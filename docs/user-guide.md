# User Guide

## Introduction

Welcome to the Car Health Check application.

The application allows users to monitor vehicle health, review alerts, and generate reports.

## Login

### Steps

1. Open the application URL.
2. Enter username.
3. Enter password.
4. Click **Login**.

## Dashboard

The dashboard displays:

- Overall Health Score
- Active Alerts
- Service Recommendations
- Recent Diagnostics

Example:

```text
Vehicle Health Score: 92%
Active Alerts: 1
Last Inspection: 12-Oct-2026
```

## Search Vehicle

### Search by VIN

1. Navigate to Vehicle Search.
2. Enter VIN.
3. Click Search.

Example:

```text
VIN: WDB123456789XYZ
```

## Vehicle Details

The following information is displayed:

- Vehicle Model
- Vehicle Status
- Mileage
- Last Service Date
- Active Issues

## Alert Management

The application generates alerts for:

- High Engine Temperature
- Low Battery Health
- Low Tire Pressure
- Sensor Malfunction

### Alert Severity

| Severity | Description |
|-----------|-------------|
| Critical | Immediate Attention Required |
| Major | Must Be Investigated |
| Minor | Informational Warning |

## Reports

Available reports:

### Vehicle Health Report

Provides:

- Overall Status
- Failed Checks
- Recommendations

### Fleet Report

Provides:

- Fleet Summary
- Vehicle Ranking
- Open Issues

## Notifications

Notifications can be received through:

- Email
- SMS
- In-App Alerts

## Frequently Asked Questions

### How often is the health score updated?

Every 15 minutes.

### Can I export reports?

Yes. Reports can be exported as PDF.

### Who can configure thresholds?

Only Administrators.

## Logout

1. Click the profile icon.
2. Select Logout.

You will be redirected to the login page.
